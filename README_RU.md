# Echo Platformer — Unity 6000.6.5f1

## Открытие
1. Распакуйте архив полностью.
2. В Unity Hub выберите **Add → Add project from disk** и укажите папку `EchoPlatformer`, в которой находятся `Assets`, `Packages`, `ProjectSettings`.
3. Дождитесь импорта и компиляции.
4. Демонстрационная сцена должна создаться автоматически. Если нет: **Echo Platformer → Create Demo Level**.
5. Откройте `Assets/Level1.unity` и нажмите Play.

## Управление
- A/D или стрелки — движение
- Space — прыжок
- E — сонар

Сцена использует собственный квадратный спрайт `Assets/WhiteSquare.png`, чтобы платформы отображались как полноценные прямоугольники, а не как тонкие контуры.
